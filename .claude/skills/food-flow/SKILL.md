# Fastify Motion Bro — AI agent production profile
This SKILL governs prompt planning, NOT automatic Google Flow image/video creation. Choose ONLY if explicitly requested; generic "start" in an otherwise fresh repo must ask which profile first. Never act on an unrelated profile's "start". Do not invent references or claim to have watched/rendered media. Approval/paid API/upload guards from AGENTS.md remain in force.
CLI: npm run profile -- start food-flow ; npm run profile -- answer food-flow '<reply or JSON>'.
The CLI output is starter production material; an expert creative agent may improve the writing without changing locked continuity or user-approved choices. The project state in projects/profiles/food-flow/session.json persists the current stage.

## Realistic fast food / all-food action prompting
START shows savory, sweet, drink and custom food choices. After food selection ask number of clips (any positive integer, recommended 3–6). Work out natural assembly steps; combine adjacent steps if too few clips, create NEW close-up details if too many, never repeat identical action. Last clip ALWAYS tasting/eating by same chef (one-clip projects produce final-tasting clip only).
Lock EXACT chef description, set, surface, light, 45-degree camera framing and no music/dialogue across every clip. EACH prompt is a single 10s Google Flow action with accurate stage-specific tactile foley (ice clinks, sauce wet scrape, baking only where genuinely necessary, crunchy/soft chew matching actual food). Don't add generic cooking/ambience in place of direct sounds. Same last-state→next-first-state action continuity. Output all clips at once with clean numbered copy-paste text blocks. After output one line instructing Flow generation and joining, then STOP.

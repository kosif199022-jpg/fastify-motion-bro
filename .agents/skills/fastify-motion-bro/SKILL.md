# Fastify Motion Bro — Production Skill
1. Read AGENTS.md, docs/QUESTIONS.md, docs/ENGINE_ROUTER.md and docs/SOURCE_AUDIT.md.
2. Study user files/links (video timing, audio, colors, styles), never assume what was not inspected.
3. Ask only missing questions **in one short Arabic message**; recommend good defaults, wait for answers when crucial.
4. Create a signed-off creative brief, timed script, STYLE.md and storyboard with motion cues for every scene.
5. Check installed tools; use implemented Native Canvas engine by default. Remotion / HyperFrames / KOSIF / Higgsfield integrations are optional and require availability validation. No unauthorized paid calls.
6. Write time-seekable animated scenes in HTML/CSS/SVG/Canvas/WebGL or Remotion. No slideshow pretending to be animation. Respect RTL, Arabic shaping, iPhone safe zones and legibility.
7. Offer playable preview and iterate before exporting. Final render only after explicit approval.
8. Export MP4, run QA, check start/mid/end and audio sync; deliver editable source, storyboard, QA receipts, and honest notes.
9. Never commit user media or API keys. Follow third-party licenses; do not copy unlicensed Higgsfield example code.

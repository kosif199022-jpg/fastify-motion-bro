# Engine Router
- Native Canvas (implemented starter): Arabic vector animation, charts, titles, time-seekable HTML canvas, local MP4 export using Chromium+FFmpeg.
- Remotion (external integration target): React scenes, long sequenced edits, Remotion Studio review, referenced motion-starter-kit.
- HyperFrames (external integration target): HTML/CSS/video rendering for code-driven cinematic compositions; check Node.js >=22 on recent releases.
- KOSIF Motion (external integration target): audio2motion, karaoke/captions, structural shape kit, voice analysis, local montage; discover tools in kosif-one and kosif-studio, avoid assuming connectivity.
- Higgsfield (external paid connection): AI-generated clips only after keys, license, terms and user permission are verified. The linked Higgsfield landing example is not a reusable SDK implementation.
- Scroll-world / brag: scroll-scrub and product-launch creative directions, not installed runtimes.
Choose based on availability and goals. Before switching a chosen engine, explain tradeoffs. No vendor code copied into this repository.

- Opt-in Viral Editorial 3D: read docs/VIRAL-EDITORIAL-DNA.md. Native original 2.5D vector renderer under web/editorial.js. No attached photoreal model generator.

- Prompt-only production profiles for Google Flow (not connected): see docs/PROFILE_CATALOG.md. Invoke npm run profile -- list.

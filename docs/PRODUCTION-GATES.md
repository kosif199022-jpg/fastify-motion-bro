# Global multi-profile production gates

- Scope exactly one selected profile at a time. 'Start' without a selected profile => ask which mode, never trigger all.
- Every mode has its own mandatory order. User-provided answers may remove redundant questions, but must not imply script approval, style lock or real render authorization.
- Lock character design, reference-image instruction, background, camera, costume and lighting as EXACT reusable blocks. Every scene carries those unchanged.
- Do not invent an unseen user's face, reference image, logo, exact car trim or historical archival authenticity.
- Time truth: 5×6s = 30s, 5×7s = 35s, N×10s = 10N. If timestamps are supplied in kinetic mode, they override word pace estimates.
- Prompt description ≠ generated still ≠ rendered video ≠ audio file. User must explicitly request and authorize any generation, third-party cost, publishing or final output.
- Flow on-screen typography is a generation request, not guaranteed spelling or layout. Clean plate is offered only on explicit request.
- Keep music/audio rules separate: Viral Editorial Stage 5 has no narration or music; Vox historical has locked narrator voice; Fitness has coach voice; Food has foley but no speech/music.
- Images from multi-character stories are independent reference keyframes; storyboard scenes and MP4 are separate production actions.
- Check gym technique and anatomical muscle overlay with qualified sources or experienced review; do not overstate confidence in physical biomechanics.
- Verify documentary historical claims and license/reference provenance before publishing.
- Unit tests prove only logic/gates, not real AI generation or cinematic quality. Render technical QA and human watch/listen are different.
- Public GitHub: never commit API keys, paid subscription tokens, user uploads or private media. Keep persistent sessions ignored.
